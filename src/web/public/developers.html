🔌 Sentinel Developer API

Real, key-authenticated endpoints for your Discord server. Base URL: /api/v1 · 25+ endpoints
🌐 Test right in your browser. Every endpoint also accepts the key as a ?key= query param, so you can try any read endpoint by pasting a URL:
https://sentinelbothq.com/api/v1/endpoints?key=sk_your_key_here
That one lists every endpoint live — it's self-documenting.

Authentication

Generate a key in Discord with !apikey new read (or write) — it's DM'd to you once. Send it as a header:

Authorization: Bearer sk_your_key_here

…or as a query param for quick browser tests: ?key=sk_your_key_here

Scopes: read stats, leaderboards, balances, live data. write everything read can do, plus economy edits + announcements.
Manage keys: !apikey list · !apikey revoke <id>.

Rate limits: a shared anti-spam limiter applies (~a couple requests/second). Live ER:LC endpoints are cached a few seconds server-side to protect the upstream game API. Every call is scoped to your key's guild.

Communication 1

POST/announcewrite

Post a message or embed to a channel in your guild.

Body: { "channelId": "123…", "content": "Hello from my app!" }
   or: { "channelId": "123…", "embed": { "title": "Hi", "description": "…" } }
→ { "ok": true, "messageId": "…", "channelId": "…" }

Full example

curl -H "Authorization: Bearer sk_xxx" \
     "https://sentinelbothq.com/api/v1/pulse"

curl -X POST -H "Authorization: Bearer sk_xxx" -H "Content-Type: application/json" \
     -d '{"amount":100,"reason":"daily bonus"}' \
     "https://sentinelbothq.com/api/v1/economy/123456789"

All write actions are logged, scoped to the key's guild, and rate-limited. Keys are stored only as SHA-256 hashes — losing one means generating a new one.
