Getting Started01

Sentinel is an all-in-one Discord bot plus a web control center. You interact three ways: slash commands (/), a big quick pack (?), and power commands (!) — plus a full dashboard.

The 60-second start

  1. Invite the bot to your server first (see §02).
  2. Run !setup or /setup or open the dashboard.
  3. Pick a log channel, enable modules, and you're live.
You never need to log in to use the bot — login is only for configuring from a browser.

Inviting the Bot02

Use an invite link with both the bot and applications.commands scopes — the second is what lets slash commands register.

https://discord.com/oauth2/authorize?client_id=YOUR_ID&permissions=8&scope=bot+applications.commands
If slash commands don't appear, the invite was missing applications.commands. ! and ? commands always work regardless.

New global slash commands can take up to an hour to appear the first time — normal Discord behavior nothing bad. See also §18 Troubleshooting.

The Web Dashboard03

The dashboard runs everything from a browser: modules, economy, tickets, leveling, announcements, live analytics, warnings, owner tools, and more across 12+ pages.

Signing in

Log in with Discord (required to manage servers) or Google. You need the Manage Server permission on any server you configure.

Pro tip: press Ctrl/⌘ + K anywhere on the site for the command palette, or set custom keys on the Controls page.

Setup Wizard05

Run !setup for an interactive, page-by-page configurator in Discord — modules, log channels, roles, economy, automod, tickets, and more. Every change saves instantly. The dashboard does the same, visually.

Moderation & Automod06

Bans, kicks, timeouts, and warnings with a full infraction ladder (warn → timeout → kick → ban) that escalates automatically. Automod guards spam, invite links, mass-mentions, and a 4,000-word filter. A file scanner blocks dangerous attachments — even renamed this stop anything bad form happening in your server .exe files.

Economy07

A full per-server game economy: wallets, banks, shop, gambling, daily rewards, and leaderboards. Configure the currency name/emoji, starting balance, and daily amount from setup or the dashboard.

Leveling & XP08

Members earn XP for chatting. Set a level-up channel and message, and configure auto-roles that unlock at specific levels. All tunable per server.

Ticket Studio09

A creative studio for support tickets: design the panel (title, color, buttons or a menu), pick channel-tickets or DM modmail, set auto-close timers, claim & transcript buttons, per-category ping roles, and feedback ratings.

ER:LC Integration10

Connect your Emergency Response: Liberty County server with /erlc link (or !erlc key) — paste your key in a private popup; stored AES-256 encrypted, never shown in chat. Then the bot reads live players, vehicles, and 911 calls, runs in-game commands, and powers the CAD.

ER:LC Regions: draw map zones and auto-move verified players between voice channels based on where they stand in Liberty County.

CAD / Dispatch11

A full dispatcher console: a live map with unit pins + 911 calls, create/assign/close calls, unit statuses, panic & Signal 100, jurisdiction drawing, and Patrol Ops — speed radar, closest-unit voice auto-dispatch, and BOLO/ALPR alerts. Open it with !cad. Access is limited to PD/EMS/DOT roles (!cadaccess add @role).

MDT & Records12

The officer's terminal: name & plate lookups, civilian records, registered vehicles, warrants, citations, a Z-key citation handout (screenshot + save + beep), a Run ID with Roblox mugshot + Discord pfp, a 66-report Report Center, a state Law Book with web law search, an AI Judge, and Jail/Bond. Open with !mdt.

AI Assistant13

Mention the bot and it answers, powered by Gemini — with web search, embed & form building, image vision, memory, and a strict moderation layer. The AI Judge and radar-station chat use the same engine, server-side, so the key never touches the browser.

Automations14

A no-code trigger→action engine. Triggers include region enter/exit, a new 911 call, or a plate being seen; actions include sending a message, granting a role, or punishing. Use variables like {player}, {region}, and {emergency.desc}. Up to 25 rules per server.

Anti-Raid & Security15

An anti-raid engine locks the server down on join-spam. Rate limiting guards every action (2 warnings → timeout → lockout). Secrets are dual-encrypted (AES-256-GCM + HMAC) and never exposed. Full server backup & restore is built in.

Developer API16

Build on top of Sentinel. Issue API keys with !apikey, then hit the GET/POST endpoints for your data. Keys are stored encrypted and shown only once. Embeddable widgets (like a live leaderboard) drop into any site by URL.

Controls & Keybinds17

Troubleshooting & FAQ18

Slash commands aren't showing

Re-invite with applications.commands in the scope, and give it up to an hour. !/? commands work instantly.

Dashboard login fails

The site's login redirect URL must match the current address in the Discord & Google OAuth consoles. If the URL changed, re-register the redirect.

ER:LC / CAD shows no data

Make sure the ER:LC key is set (/erlc link) and the server is online. Test with /erlc server.

Still stuck? Type !update in Discord for the full changelog, or visit the status page.
